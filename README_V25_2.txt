Elevor360D Marketplace Pro V25.2

1. Back up existing local data and CSV records.
2. Run SUPABASE_V25_2_PHOTOS.sql in your Supabase SQL Editor ONCE.
3. Copy your working marketplace-config.js from V25.1 to this folder.
4. Upload all files to your GitHub Pages repository, including sw.js.
5. Reload on desktop/tablet/phone; use App Health & Updates if an older copy appears.

Upload photo: Cloud Listings > Publish a Product Online > Choose File / gallery. Select a JPG/PNG/WebP/GIF under 5 MB and Publish Online. Photos are PUBLIC.
Delete cloud listing: sign in as its seller > Cloud Listings > My cloud listings > Refresh My Cloud Listings > Delete Cloud Listing > confirm.

NOTE: deleting a listing does not delete its stored photo. Contact the site administrator to remove orphaned photos from Supabase Storage. If deleting a listing fails due to linked messages or reports, contact the administrator; do not disable RLS.

Testing: upload a photo from mobile and desktop, verify its display in Cloud Listings, delete a disposable test listing, and verify that another seller cannot delete it.
