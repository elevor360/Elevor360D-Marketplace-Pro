Elevor360D Marketplace Pro V18 — Direct Seller-Arranged Payments

1. Export a backup in V17.
2. Copy your configured marketplace-config.js from V17 into this folder. NEVER include secret/service-role keys.
3. Upload the contents of this folder to your existing GitHub Pages repository, replacing prior files.
4. Refresh/reopen the installed app. If necessary close all app tabs and refresh again.
5. Open a published cloud product > View Details > Arrange Payment.
6. Use Messages or external contact options to agree payment and delivery directly with the seller.
7. Open Payment Arrangements to record private notes and tracking status.
8. Export a new backup to include the private payment arrangement notes.

No Supabase SQL changes required for V18. The private notes are stored on each device only and are NOT sent to the seller or synced online. 'Completed' is self-reported, NOT proof of payment. No checkout, deposits, bank data, escrow, or transaction verification is provided.

Test existing cloud listings, messaging, ratings, reporting and admin controls.
