Privacy & Security · V22

Manage optional records saved on this device. Your online listings, messages, account and reviews are stored separately in Supabase and are not deleted by these controls.

How information is stored

  • Public online listings and seller profiles are visible to visitors.
  • Account sessions and private messages use Supabase authentication and database permissions.
  • Local drafts, favourites, enquiry logs, offers, payment notes and transaction records remain in this browser unless exported or cleared.
  • Other users of this device/browser may be able to view locally saved information. Sign out on shared devices.
  • The app does not process card payments or confirm money transfers.

Online account and data

To request deletion of your online account, messages, listings or reviews, contact the marketplace administrator. This release does not provide automatic online account deletion. The site owner must establish and publish a privacy notice and contact method before public launch.

Security advice

About Version 24

This version adds authenticated cloud publishing and secure Supabase cloud browsing to the offline-installable foundation for Elevor360D Marketplace Pro. Prepare and track price offers locally, prepare seller enquiries, maintain a local enquiry log, save favourite items, create and edit listings with up to four photos, duplicate listings, manage inventory with dashboard statistics and filters, record completed sales, mark items sold, browse products, and back up or restore your data.

Important: Sales records and your listings are currently visible only in this browser on this device. Customer accounts are now supported; online payment processing is intentionally not included; buyers and sellers arrange payment independently. Offers are drafts tracked on this device, not automatically delivered or accepted. Enquiries are prepared locally, not delivered by this app. Those features are planned for later versions and will require an online service.

Install

Upload all files to a HTTPS host such as GitHub Pages. In Chrome or Edge, use the Install App button when offered, or the browser's install option. iPhone users can use Safari's Share → Add to Home Screen.

Backup

Use My Listings → Export Backup to save a JSON file. Restore replaces the current listings after confirmation.
