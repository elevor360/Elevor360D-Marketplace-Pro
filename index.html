About Version 16

This version adds authenticated cloud publishing and secure Supabase cloud browsing to the offline-installable foundation for Elevor360D Marketplace Pro. Prepare and track price offers locally, prepare seller enquiries, maintain a local enquiry log, save favourite items, create and edit listings with up to four photos, duplicate listings, manage inventory with dashboard statistics and filters, record completed sales, mark items sold, browse products, and back up or restore your data.

Important: Sales records and your listings are currently visible only in this browser on this device. Customer accounts are now supported; authenticated cloud seller uploads, online payments are not yet connected. Offers are drafts tracked on this device, not automatically delivered or accepted. Enquiries are prepared locally, not delivered by this app. Those features are planned for later versions and will require an online service.

Install

Upload all files to a HTTPS host such as GitHub Pages. In Chrome or Edge, use the Install App button when offered, or the browser's install option. iPhone users can use Safari's Share → Add to Home Screen.

Backup

Use My Listings → Export Backup to save a JSON file. Restore replaces the current listings after confirmation.
