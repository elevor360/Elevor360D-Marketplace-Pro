Elevor360D Marketplace Pro V20 — Private Transaction Records

1. Export a backup from V19.
2. Copy your configured marketplace-config.js from V19 into this folder.
3. Upload all files to the same GitHub Pages repository.
4. Refresh the app (close and reopen if service worker cache persists).
5. Open any listing, choose Record Arrangement, then use Transaction Records to edit status, agreed amount and private notes.
6. Export CSV to keep a separate copy of transaction records.

No new Supabase SQL required. Transactions are local to each device, NOT synced to Supabase or sent to buyers/sellers. No payment processing, invoices or receipts are generated. Existing local backup does NOT include transaction records; export CSV separately.
